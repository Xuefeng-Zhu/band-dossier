# Buildathon submission checklist

The event’s project submission announcement gives **November 30, 2026 at 5 p.m. Pacific** as the deadline. Submit this public repository, the presentation and the demo video through the HackerSquad project workspace. [Event announcement](https://luma.com/band-ai-hacks-nov13-2026) · [HackerSquad workspace](https://hackersquad.io/builders/dashboard/events/cmvjphjn60001mu23sgymnfzn/builder#project)

## Repository

- [ ] Write the entrant’s final [README](../README.md) and [FACTORY](../FACTORY.md) in their own words. Confirm the README team name and roster against HackerSquad. In FACTORY, explain the setup, the design choices, the measured costs and examples of how review corrected failures.
- [x] Include each accepted stage as a separate buildable directory, the [three generic seat mandates](../mandates/), the [full Band room export](../room.json) and the [verbatim live Stage 4 Runway response](../dossier-runway.com.json).
- [ ] After the final documentation is committed, clone the public repository and rerun the [submission checks](verification.md#reproduce-the-organizer-checks). Follow each stage’s `RUN.md` and confirm the browser screens load.

## Presentation and demo

- [ ] Use the corrected run in the presentation. Explain why the three seats had separate responsibilities, what the 91-minute run cost in model usage, one finding the Reviewer caught, and what reached Stage 4. [Factory draft](../FACTORY.md)
- [ ] Record the actual Band room and a handoff, then show the resulting Dossier UI. One sequence is the Reviewer’s Stage 1 currency finding, the Implementer’s corrected candidate, the Reviewer’s acceptance and the resulting Stage 4 interface. Use the live JSON to show how `known`, `contested` and `unknown` fields are represented. [Judged Band room](https://app.band.ai/rooms/b29960b3-2952-449d-bb03-185157ac327a) · [Live response](../dossier-runway.com.json)
- [ ] Enter the public repository URL `https://github.com/Xuefeng-Zhu/band-dossier` in HackerSquad. Supply the presentation through the event’s delivery method, select the processed demo recording, submit for judging and save the receipt. [Official participant guide](https://github.com/band-ai/sf-buildathon-2026/blob/704324580f8ac1f893dc2e0a0339b9b3905e7707/docs/participant-guide.md#check-and-submit)

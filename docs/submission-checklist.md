# Buildathon submission checklist

The event’s project submission announcement gives **November 30, 2026 at 5 p.m. Pacific** as the deadline. Submit this public repository, the presentation and the demo video through the HackerSquad project workspace. [Event announcement](https://luma.com/band-ai-hacks-nov13-2026) · [HackerSquad workspace](https://hackersquad.io/builders/dashboard/events/cmvjphjn60001mu23sgymnfzn/builder#project)

## Repository

- [ ] Write the entrant’s final [README](../README.md) and [FACTORY](../FACTORY.md) in their own words. Confirm the README team name and roster against HackerSquad. In FACTORY, explain the setup, the design choices, the measured costs and examples of how review corrected failures.
- [x] Include each accepted stage as a separate buildable directory, the three seat mandates and the verbatim live Stage 4 Runway response. [Accepted commits](verification.md) · [Mandates](../mandates/) · [Runway response](../dossier-runway.com.json)
- [ ] If submitting this branch, replace the baseline export at `room.json` with the fresh run’s full session export. [Fresh Band room](https://app.band.ai/rooms/56bc7b26-1280-4cbd-ab75-36492a7d432c) · [Organizer instructions](https://github.com/band-ai/sf-buildathon-2026/blob/704324580f8ac1f893dc2e0a0339b9b3905e7707/docs/participant-guide.md#record-the-room)
- [ ] After the entrant’s final edits, run the [submission checks](verification.md#reproduce-the-organizer-checks) from a fresh clone of the revision the organizers will judge. Follow each stage’s `RUN.md` and confirm the browser screens load.

## Presentation and demo

- [ ] Use the run selected for submission in the presentation. Explain the three seat responsibilities, delivery time, measured usage and what reached Stage 4. Include a review finding and how the band resolved it. [Verified baseline factory](../FACTORY.md) · [Fresh run verification](verification.md)
- [ ] Record the selected Band room and a handoff, then show its Stage 4 UI. In the fresh run, Stage 1 review found a dropped USD expression and accepted the corrected candidate. Use the live JSON to show how field statuses are represented. [Fresh Band room](https://app.band.ai/rooms/56bc7b26-1280-4cbd-ab75-36492a7d432c) · [Fresh Runway response](../dossier-runway.com.json)
- [ ] Confirm the public repository URL resolves to the intended submission revision before entering it in HackerSquad. Supply the presentation through the event’s delivery method, select the processed demo recording, submit for judging and save the receipt. [Public repository](https://github.com/Xuefeng-Zhu/band-dossier) · [Official participant guide](https://github.com/band-ai/sf-buildathon-2026/blob/704324580f8ac1f893dc2e0a0339b9b3905e7707/docs/participant-guide.md#check-and-submit)
